  - Назначение: полное управление AWS ресурсами

  - Группа: DeveloperGroup
  - Политики: AmazonAPIGatewayAdministrator, AWSCloudFormationFullAccess, AWSLambda_FullAccess, IAMFullAccess и другие
  - Назначение: разработка и тестирование

- `IaM-1@Developer_IDE.7125` - программный доступ для IDE
  - Ключ доступа: активен
  - Назначение: работа из IDE и локальная разработка

- `IoTMonSys@ApiClient.7125` - специальный пользователь для проекта
  - Политика: IoTMonSys-ApiClientPolicies
  - Ключ доступа: активен
  - Назначение: доступ к AWS сервисам из приложения

**Политики безопасности:**
- `IoTMonSys-ApiClientPolicies` - минимальные права для работы приложения:
  - API Gateway: execute-api:Invoke для конкретных endpoints
  - CloudWatch Logs: logs:CreateLogGroup, logs:CreateLogStream, logs:PutLogEvents, logs:DescribeLogStreams
  - Ресурсы ограничены конкретными ARN для повышения безопасности
